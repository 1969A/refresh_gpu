# Refresh GPU 🔄

Un script simple et rapide permettant de réinitialiser/redémarrer le pilote graphique de votre carte vidéo sous Windows sans avoir à redémarrer tout le système.

Useful en cas de freeze d'affichage, de glitchs visuels lors du lancement d'un jeu ou d'une application lourde, ou après une mise à jour/undervolt.

---

## 🚀 Fonctionnalités

- **Réinitialisation rapide** du pilote d'affichage Windows (équivalent au raccourci clavier `Win + Ctrl + Shift + B`).
- **Pratique & Automatisable** : Exécutable via un simple double-clic ou directement intégré dans vos scripts Batch / PowerShell.
- **Léger & Sans installation** : Ne nécessite aucun logiciel tiers.

---

## 💻 Utilisation

1. **Méthode Manuelle (Raccourci Windows)** :
   - À tout moment sous Windows, appuyez simultanément sur `Win + Ctrl + Shift + B`.
   - L'écran clignotera brièvement et un bip sonore se fera entendre, confirmant le rafraîchissement du pilote.

2. **Via le Script du Repository** :
   - Téléchargez ou clonez ce dépôt :
     ```bash
     git clone [https://github.com/1969A/refresh_gpu.git](https://github.com/1969A/refresh_gpu.git)
     ```
   - Lancez le fichier binaire ou de commande présent dans le dossier.

---

## 🛠️ Prérequis

- **Système d'exploitation** : Windows 10 / Windows 11.
- **Cartes graphiques compatibles** : NVIDIA, AMD Radeon, Intel Graphics.
